## 📌 Sobre el proyecto

**Red Peluda** es una iniciativa digital diseñada para transformar la vida de animales sin hogar al facilitar procesos de adopción sencillos, transparentes y seguros. La plataforma permite a los usuarios conocer las mascotas disponibles para adopción, entender los requisitos del proceso, contactar directamente con el equipo y enviar solicitudes formales de adopción a través de un sistema interactivo de ventanas modales .

La aplicación está construida utilizando **HTML5**, **CSS3** y **Bootstrap 5**, garantizando una experiencia de usuario fluida y un diseño completamente adaptativo (responsive), accesible desde cualquier dispositivo .

---

## ✨ Características de la plataforma web

El sitio cuenta con diferentes secciones orientadas a dar a conocer nuestra labor, los peluditos disponibles y los requisitos para adoptar:

* 🏠 **Página Principal (`index.html`):** Presentación general de la plataforma con una sección descriptiva e ilustrativa.
* 👥 **Sección Quiénes Somos (`about.html`):** Información institucional sobre la labor de la plataforma.
* ✉️ **Sección de Contacto (`contact.html`):** Formulario completo de contacto para consultas generales, solicitudes de información o voluntariado.
* 🐶 **Sistema Interactivo de Adopción (Modal):** Modal emergente global integrado en todas las páginas mediante Bootstrap 5, activable a través del botón **"¡Adoptar Ahora!"** .
* 📱 **Diseño responsive:** adaptación a diferentes tamaños de pantalla.

## 🖥️ Ejecutar el proyecto localmente

Como se trata de una plataforma web estática, puedes ejecutarlo directamente desde tu equipo.

### 1. Clonar el repositorio

```bash
git clone https://github.com/SneyderRodriguez/RED-PELUDA.git
```

### 2. Entrar al proyecto

```bash
cd RED-PELUDA
```

### 3. Ejecutar

Puedes abrir directamente el archivo:

```text
index.html
```

También puedes utilizar una extensión como **Live Server** en Visual Studio Code para ejecutar el proyecto mediante un servidor local.
